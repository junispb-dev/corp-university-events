# Мероприятия Корпоративного университета

Статическая страница календаря мероприятий ГК «Спектрум».

## Как открыть локально

Откройте файл `index.html` в браузере (двойной клик) или через локальный сервер:

```bash
npx --yes serve .
```

## Как опубликовать на GitHub Pages

1. Repository → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)` → Save
4. Сайт будет по адресу: https://junispb-dev.github.io/corp-university-events/

В репозитории есть пустой файл `.nojekyll`, чтобы GitHub не обрабатывал страницу через Jekyll.

## Где править данные

Все мероприятия — массив `spectrumEvents` в `index.html`.
У каждого события должны быть валидные `dateStart` / `dateEnd` в формате ISO
(например `2026-11-19T10:00:00+03:00`). Плейсхолдеры вроде `__:__` ломают отображение.
`id` у каждой записи должен быть уникальным.
